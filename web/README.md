# Course Planner (web)

The Temple course planner demo: pick a term, find courses, plan the week, review before registering in Banner.
Data for two programs (Computer Science BS and Management Information Systems BBA, 2026–2027 bulletin) lives in `src/data`: no API calls and no environment variables. See the root README for how the data was gathered.
Run it with `npm install`, then `npm run dev`, and open http://localhost:3000.
Build it with `npm run build`. Node 20.9 or later.
